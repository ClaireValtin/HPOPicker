# HPO Picker

Browse the Human Phenotype Ontology, tick the terms that describe a patient, and export the list.

**Open it:** https://clairevaltin.github.io/HPOPicker/

## What it does

- **Browse and search** the full HPO tree, organised by organ system
- **Select** the terms that describe your patient; each one shows the English term and its French equivalent
- **Add consultation details** (name, record number, dates, physician, notes) for the printed sheet
- **Export** as a printable sheet or PDF, an HTML report, a table (`.tsv`), or a plain list of HP IDs to paste into a variant analysis pipeline
- **Save and reopen** a session as a `.json` file

Everything runs in your browser. Patient details are not sent anywhere.

## How to use

Open the link above. Nothing to install.
